# Database (SQLite)

This workspace includes helper scripts to initialize and work with a SQLite database.

Useful scripts:
- init_db.py: Creates a sample SQLite DB (myapp.db) and writes db_connection.txt
- db_shell.py: Interactive SQLite shell helper

Note:
- The Todo backend creates and manages its own SQLite file at simple-todo-application-188632-188641/todo_backend/todo.db automatically.
- No additional setup needed for running the Todo app.
